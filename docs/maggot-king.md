# Maggot King encounter

The quest-gated Darkwood trees open a solo copy of the actual Maggot King's lair. Its 1500HP boss starts ranged, alternates ranged and magic around screeches, introduces larvae and melee as its health falls, and finishes in melee. Only the owner can attack its boss or larvae. Leaving, logout, death, instance destruction and server shutdown stop the encounter; a kill stops its effects and permits a fresh spawn in the same room.

Combat and recovery are implemented. Corpse choice and reward acquisition, upstream generated drop repair, collection-log/Combat Achievement reconciliation and sticky-bile bracelet protection remain separate work. No generated definitions or drop tables are patched here. Native NPC death/damage attribution remains authoritative; the plugin records the owner's kill count for the displayed counter and the first-five-kill grave discount.

Until corpse-choice rewards are implemented, actors spawned by this encounter suppress the generic NPC death-loot roll. This prevents premature Take-eggs tertiary loot behind the bone wall. Suppression follows the original actor after death/session cleanup; unrelated NPCs with the same ID retain ordinary drops. This does not implement either corpse reward option.

Already-owned Maggot eggs support their native inventory **Pop** action. One action consumes one egg and makes one roll for Maggot marquess: base1/3000, sickly1/2500, warm1/1250, pulsating1/500, wriggling1/10 and writhing1/2. The six subtypes share a display name but use distinct cache IDs; placeholders cannot be popped. Pet ownership, duplicates, follower/inventory delivery, full-pack insurance and collection-log updates use the existing `pets:award` consumer. A duplicate or ineligible award does not refund the consumed egg. The failure message is descriptive server wording, not an observed retail line; no animation or automatic batch cadence is inferred.

Accurate ordinary Fire Strike/Bolt/Blast/Wave/Surge impacts against the current owner’s boss request a five-damage burn from the existing shared burn engine. That engine owns four-tick pulses, the five-stack cap, discard-at-cap behavior, attribution and expiry; encounter closure clears the actor’s burns through its native clear event. A splash, another spell or a different actor/session does not gain this producer.

Magic defence composes the actual current NPC bonus, the near stance’s +250 and minus20 per live native burn stack in the existing encounter roll hook. It does not drain Magic/Defence levels or overwrite permanent bonus overrides such as Soul Rend. The shared remaining-burn query now exposes its actual native stack count as well as remaining damage; a damage total cannot determine the count when stack durations differ. Two unmeasured edges use disclosed implementation policies: count all native player-inflicted burn stacks (including mixed producers), and floor the composed effective magic-defence bonus at0. Neither mixed-source behavior nor that minimum is claimed as observed retail behavior.
