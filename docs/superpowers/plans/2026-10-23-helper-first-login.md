# Quest Helper first-login guidance

Requested: enable Quest Helper by default and give new accounts a clear starting point.

1. Enable the plugin by default while respecting an explicit saved off preference.
2. With no selected guide, select unfinished Tutorial Island from the authoritative catalog and open its panel once. Do not restart it after Stop helping or replace a manually selected guide.
3. Show an unfinished tutorial first, then in-progress quests and a small curated set of beginner suggestions. Omit completed/unsupported routes, deduplicate variants, and label suggestions without claiming full prerequisite checks.
4. Mark a completed selected quest in the session catalog so the next suggestions update immediately.
5. Verify fresh-account defaults, guide selection/stop/account lifecycle, recommendation rendering and existing helper tests; rebuild and check the installed browser using a separate account. Client-only deployment needs no game restart.

This focused implementation uses the existing sidebar and helper transport. It does not automate gameplay.
